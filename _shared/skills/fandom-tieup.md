# スキル：IP協業・ファンダムタイアップ設計

**使用するエージェント：** insight-analyst（IPリサーチ・ファンダム分析）／ content-strategist（タイアップ企画・伝搬設計）
**入力：** 自社ブランド・商品の課題／ターゲット層／予算感／候補IP（あれば）
**出力：** IP選定シート・タイアップ企画書・伝搬設計・KGI/KPI設計

---

## 前提となる基本概念

### トライブ・ファン・ファンダムの違い

タイアップの対象を正しく見極めるため、まずこの3層を区別する。

| 層 | 可処分精神 | 優先順位 | 含有規模 | 熱狂濃度 |
|---|-----------|--------|---------|---------|
| **トライブ** | なし | 高くない（「好き」の一種） | 最大 | 低い |
| **ファン** | なし | 優先的に時間・お金を投下するが他の「好き」と比較検討する | トライブ未満・ファンダム以上 | 中程度（状況による） |
| **ファンダム** | あり | 最優先で時間・お金を投下。ただし推しの動きにはシビア | 最小 | 高い |

**戦略上の意味**：ファンダムは濃度が高い分、母数が狭い。「広げる」施策には後述の越境設計でトライブ層を活用する。

## STEP 1：目的設定（ファンダムブランディング／ファンダムプロモーションの選択）

ファンダムタイアップには2種類あり、最初にどちらを狙うかを明確にする。混同すると狙った結果が出ない。

| 種別 | 目的 | アプローチ領域 |
|-----|------|------------|
| **ファンダムブランディング** | 認知度・好意度・想起度・推奨意向度の引き上げ | 意識変容・態度変容 |
| **ファンダムプロモーション** | 購買意向・店頭送客・実購買・行動意欲の向上 | 行動変容（売上に近い） |

**重要な原則**：戦略（何のためにやるか）はブランド・企業側が主体で設計し、戦術（どうやるか）はIP（のファンダム）側を主体に据える。自社ターゲットとIPターゲットの親和性だけで判断すると失敗する。あくまで「自社ブランド・商品の課題解決」が起点。

## STEP 2：目標設計（KGI／KPI）

### KGI

| 種別 | KGI設定の傾向 | 測定方法 |
|-----|------------|---------|
| ファンダムプロモーション | 売上（ただし要因特定の解像度は低くなりやすい） | POSの動き・レシート応募数・ECの指定タグ／特設サイト経由の購入数 |
| ファンダムブランディング | 好意度・推奨意向度・愛着度・購入意向 | SNS上の定性コメント、またはブランドリフト調査で定量化。単年ではなく数年単位で見る |

### KPI（両者共通で見る項目）

- インプレッション
- 再生回数
- サイト訪問者数
- 会員登録者数
- SNS上でのエンゲージメント率（反応数）
- 定性コメント

## STEP 3：IP属性の理解

IPは大きく3カテゴリ・12ジャンルに分かれ、それぞれファンダムの特性が異なる。

### 二次元（キャラクター）

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **アニメ・漫画** | 漫画→アニメ化→映画化の過程でファンダムの母数・熱量が拡大。アニメ化の成否がファンダム形成を大きく左右する。マス化するとタイアップが乱立し、ブランド連想が薄まりやすい |
| **キャラクター** | ファンダムの含有数が最大。普遍性を獲得したキャラクター（ディズニー・ジブリ・キティ等）は半永久的にファンダムを生む。それ以外は期間限定ファンの可能性があり鮮度の見極めが必要 |

### 三次元（実在人物）

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **アイドル** | 規模・熱量ともに大きい。トータル訴求が可能。ファンダムプロモーション向き。マス起用は半年以上前からのスケジュール確保が必要 |
| **K-POP** | 男女とも規模・熱量が大きく同性ファンダム率も高い。プロモーション・ブランディング両方対応可能。活動寿命の短さ・兵役等のリスクに留意 |
| **音楽アーティスト** | レジェンド級はファンダムは多いがライト層が少ない。新人は母数少なく熱量高い。ブランディング寄りの起用が効果的 |
| **スポーツ** | チーム単位のファンダムが選手単位より母数が多い（大谷翔平等の例外あり）。文脈接続の難度が高くブランディング向き |
| **俳優** | 役へのファンダムか本人へのファンダムかを見極める（写真集売上が参考指標）。ブランディング向き |
| **2.5次元俳優** | 二次元＋三次元の相乗効果で大きなファンダムを形成しやすい |
| **ミュージカル** | 熱量は大きいが母数は少なめ。国民級の劇団以外は作品軸・役者軸のファンダムが中心 |
| **声優** | 声優自身とキャラクターのファンダムが分離している。ファンダムプロモーション向き |
| **お笑い芸人** | ネタ以外（思想・人間性の発信）でファンダム化するケースに注目 |

### バーチャル

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **Vtuber** | 熱量が非常に高い。スキャンダルリスクが低い |
| **YouTuber/インフルエンサー** | 栄枯盛衰が激しい。炎上リスクにも留意。KOL（専門領域インフルエンサー）は別枠 |
| **ゲーム** | ハード／ソフト／キャラクターの3分類。メディアミックス展開でライト層が拡大しやすい |

## STEP 4：自社接続の検証（IPと自社をつなげる8ヶ条）

IP選定は「今勢いがあるから」という手段の目的化を避け、以下8項目をすべて確認する。

```markdown
## IP選定チェックリスト

- [ ] ファンのデモグラがターゲットと一致するか
- [ ] コストパフォーマンスと見合うか（キャスティング費だけでなく、オリジナルコンテンツ制作・衣装/メイク・書き下ろし・SNS告知など想定稼働を精緻化したか）
- [ ] デジタルで強力なパワーを持つか（フォロワー数は決定打ではないが、ファンダムの含有率・共犯関係構築の可能性を見る）
- [ ] ブランドと掛け合わせるエンタメのトンマナが合っているか（世界観・思想・スタンス・クリエイティブの整合性）
- [ ] アクション（購買・口コミ・推奨）するファンダムがついているか
- [ ] 過去に同業種でのコラボ事例はないか（IP側にとってそのカテゴリーが「初」であるほど熱狂を生みやすい）
- [ ] （人物IPの場合）本人が自分の言葉で語れるか（「言わされている感」は逆効果）
- [ ] ファンダムが喜ぶものになっているか（企業の課題解決とファンダムの喜びを両立できているか）
```

## STEP 5：IP洗い出し（候補が無い場合の2つの方法論）

1. **自社の商品のクチコミをつぶさに観察する**：SNS・レビューの関連語分析で、思わぬIP名が言及されているケースを発見する
2. **自社内で推し活をしている社員にヒアリングする**：社内アンケート等でブランド・商品との関連性を導き出す

## STEP 6：IPの解像度を上げるリサーチ

```markdown
## IPリサーチ実施項目

### 現地現物
- ライブ・イベントに実際に足を運ぶ（デモグラの乖離、服装・持ち物・同伴者・物販の売れ筋・リアクション・ライト層/ファンダム比率を観察）

### SNS上の口コミ確認
- 直接（公式アカウントの発信）と間接（クチコミ分析・ネットニュース）の両方を調査
- フォロワー数より「濃度」を重視：コメント数・反応スピード・お気に入り数・コメント内容の質。数百〜千件は目視確認する

### IP側への直接ヒアリング
- NDA締結の上、再生回数・ファン属性・支持国・反応の良いコンテンツ等、ステークホルダーしか持たない情報を確認する

### 他社事例調査
- 固有名詞またはジャンル軸で先行事例を調査する（参考情報として扱い、同一IP起用の前提にはしない）
```

## STEP 7：ターゲティング（IPをどのゾーンで狙うか）

縦軸「マス（みんな知っている）／ニッチ（一部が知っている）」×横軸「可処分精神 高／低」の4象限で判断する。

| 象限 | 特徴 | 評価 |
|-----|------|------|
| **マス×可処分精神高** | 規模・熱量ともに最大だが、メガブランド以外は起用困難。高コスト・高頻度使用によるブランド連想の希薄化・厳格な使用ルールが弱点 | メガブランド向け |
| **マス×可処分精神低** | リーチはできるがファンダムが少なく、ヒトもモノも動かない | タイアップ非推奨（従来型の認知目的なら可） |
| **ニッチ×可処分精神高（セグメントマス）** | 最も多くの企業が組みやすいゾーン。低コスト・低使用頻度でブランド連想がされやすく、「フックアップしてくれた」という好意的解釈（オタクの恩返し）が生まれやすい | **最推奨** |
| **ニッチ×可処分精神低** | 対象外 | 除外 |

### セグメントマスを見つける5つの方法

1. **専門メディアで見つける**：プラットフォーマーのネクストブレイク紹介企画・ランキング（3位以下が狙い目）
2. **キュレーターから見つける**：各業界の「発掘屋」的存在のSNSをフォローする
3. **専門のファンダムに尋ねる**：「今後どうなっていくと思うか」という未来展望をヒアリングする
4. **ライブ会場の規模で見つける**：目安はZeep（2,000人）以上・武道館未満
5. **3〜4番手を見つける**：作品内の3〜4番手の役者・出演者に着目する

## STEP 8：ファンダムの存在見極め

### 定量で測る

```markdown
## ファンダム定量チェック項目

### ソーシャルメディア
- IP名・キャラクター名・名セリフ・ジャンル略語での検索、ハッシュタグ投稿数の時系列推移
- 「いいね」「リポスト」「コメント」「シェア」数とその割合

### 掲示板・クローズドコミュニティ
- 5ちゃんねる等のスレッド立ち上げ頻度・レス数・「勢い」
- Discordサーバーのメンバー数・チャット頻度

### 動画プラットフォーム
- レビュー・考察・MAD（二次創作動画）・歌ってみた・実況・切り抜きの視聴回数/高評価数/コメント数
- ライブ配信の同時接続数・スパチャ/ギフト量

### EC・グッズ・フリマ
- Amazon/楽天/アニメイトオンライン等の売上ランキング・在庫切れ頻度・即完売状況
- メルカリ等の価格動向・取引量（定価超えの高値取引は強い需要のシグナル）

### イベント参加
- チケット完売速度・抽選倍率・開催頻度と規模
- コミックマーケット等での二次創作サークルの出展数・配置スペース数
```

### 定性で測る

```markdown
## ファンダム定性チェック項目

- 投稿内容が「好き」の表明に留まらず、深い考察・分析に及んでいるか
- 二次創作（ファンアート／フィクション／MAD／コスプレ）の質・量・独創性
- pixiv/BOOTHでの作品数・閲覧数・販売実績
- 作品独自の略語・スラング・内輪ネタ・決め台詞が自然に共有されているか
- ファンネーム／ファンダムネームの有無（組織的・高熱量の強力なシグナル）
- 「推し活」文化の確立度（誕生日広告出資・グッズ収集の熱量等）
```

**判断の原則**：定量だけで判断すると「数値が高いだけ」のIPを選ぶリスクがある。定性データを同等以上に重視する。

## STEP 9：予算設計

### ファンダムのお金の優先順位

推しへの可処分所得は無限ではなく、以下の優先順位で使われる（優先度が下がるほどタイアップの効果は限定的になる）。

1. ライブ・ツアー
2. イベント・グッズ・ファンクラブ
3. コラボ商品・アイテム

IP側のメイン活動（ライブ・ツアー等）が繁忙な時期は、コラボ企画の優先順位が相対的に下がる点をあらかじめ織り込んでKGI（特に売上目標）を固めに設定する。

### 予算配分の目安

- 一般的な推し活の月間支出目安：約16,000円前後（2万円を超えない範囲に収める企画は成功確率が高い）
- お土産（インセンティブ）予算：全体予算の**最大10%**を目安に変動費として確保する

## STEP 10：コンテンツ設計

タイアップの核は「広告ではなくコンテンツを作る」という思想。以下2つの感覚をどちらか、または両方含める。

| 感覚 | 定義 | 欠けた場合のリスク |
|-----|------|-----------------|
| **わかってるね感** | 推しの文脈・背景を理解している納得感 | ネガティブな反応・炎上リスク |
| **そうきたか感** | ファンの想像を超える意外な結びつき（サプライズ） | 「大それたこと」である必要はなく、ファンダムから見て新しい切り口であればよい |

## STEP 11：伝搬設計

コンテンツを作るだけでは伝わらない。「どこで着火し、どこに広げ、どこで見せるか」をSNS単位で設計する。

| 役割 | 定義 | 該当しやすいSNS |
|-----|------|--------------|
| **着火SNS** | クチコミを最初に生む場所（コンテンツそのものは不要） | 対象ファンダムの主戦場を個別リサーチして判断 |
| **拡散SNS** | 情報を広げる場所 | X・TikTok（Instagramは閉じたコミュニティの集合体のため拡散向きではない） |
| **受け皿SNS** | コンテンツを享受する場所 | 任意のSNS／Webサイト等 |

### 発信順序のルール（「企業とともに発話させる」）

```markdown
## 発信ルール

1. 一次情報は必ず企業・ブランド側から発信する（IP公式から先に発信しない）
   → ファンダムに「Presented by」「Supported by」の文脈を持たせる
2. IP側の発信には必ず企業名・商品名を入れ込む（クリエイティブ本体には必須ではない）
   → 「誰がこのコンテンツを生み出したのか」を明確にする
3. 独自ハッシュタグで両者の結びつきを可視化する
4. （人物IPの場合）IP本人からコラボへの言及・意義表明をしてもらう
```

## STEP 12：お土産設計

お土産（特典）は販促寄りのファンダムプロモーションに紐づく要素。以下の原則を守る。

```markdown
## お土産設計チェックリスト

- [ ] そのIPのファンダムにとって「意味のあるもの」になっているか（安直に定番グッズ化していないか）
- [ ] 「ここでしか」の新規性・唯一無二性があるか（既視感のあるものはNG）
- [ ] お土産がコンテンツの主役になっていないか（核はあくまでコンテンツ。インセンティブ単体では効果が一定に留まる）
- [ ] ベーシック路線／レア路線のどちらを選ぶか、理由を持って決めているか
- [ ] 予算は全体の最大10%に収まっているか
```

## STEP 13：越境設計（ファンダムを超えて広げる）

ファンダムは濃度が高い分、母数は狭い。広げるフェーズでは以下4つの手法を使う。

### 近距離トライブス戦略

ファンダムに隣接する「好きなもの」（トライブ）はパーソナライズ化された情報流通の中でつながっている。ファンダムだけでなく隣接トライブへのアプローチを設計する。

### 主戦場を越境ドライブで広げる

自社市場をど真ん中に据えつつ、市場に隣接するトライブを「主戦場」として捉え直す。

### PRで広げる

情報は「自分ゴト」→「仲間ゴト」→「世の中ゴト」の順で広がる。

| 段階 | 定義 | 主なチャネル |
|-----|------|-----------|
| 自分ゴト | 「私に関係がある」と認識される状態 | — |
| 仲間ゴト | 特定コミュニティ内で話題になっている状態 | X・Instagram等の細分化SNS |
| 世の中ゴト | 誰に話しても知っている状態 | テレビ・Yahoo!ニュース等マスPR |

**原則**：すべてが「世の中ゴト」を目指す必要はない。根幹である「自分ゴト」「仲間ゴト」を疎かにして「世の中ゴト」だけを狙うと失敗する。

### 社会ゴトで広げる

世の中の人が反応しやすいイベント・モーメント（進学/就職・転職/引っ越し・結婚/恋愛・季節・恒例イベント・社会的ビッグイベント・記念日・トレンド）と掛け合わせ、興味指数の最大公約数を狙って局所的な影響を拡散させる。
