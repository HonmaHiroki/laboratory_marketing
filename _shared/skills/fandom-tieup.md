# スキル：IP協業・ファンダムタイアップ設計

**使用するエージェント：** insight-analyst（IPリサーチ・ファンダム分析）／ content-strategist（タイアップ企画・伝搬設計）
**入力：** 自社ブランド・商品の課題／ターゲット層／予算感／候補IP（あれば）
**出力：** IP選定シート・タイアップ企画書・伝搬設計・KGI/KPI設計

---

## 前提となる基本概念

### トライブ・ファン・ファンダムの違い

タイアップの対象を正しく見極めるため、まずこの3層を区別する。

| 層 | 可処分精神 | 優先順位 | 含有規模 | 熱狂濃度 |
|---|-----------|--------|---------|---------|
| **トライブ** | なし | 高くない（「好き」の一種） | 最大 | 低い |
| **ファン** | なし | 優先的に時間・お金を投下するが他の「好き」と比較検討する | トライブ未満・ファンダム以上 | 中程度（状況による） |
| **ファンダム** | あり | 最優先で時間・お金を投下。ただし推しの動きにはシビア | 最小 | 高い |

**戦略上の意味**：ファンダムは濃度が高い分、母数が狭い。「広げる」施策には後述の越境設計でトライブ層を活用する。

## STEP 1：目的設定（ファンダムブランディング／ファンダムプロモーションの選択）

ファンダムタイアップには2種類あり、最初にどちらを狙うかを明確にする。混同すると狙った結果が出ない。

| 種別 | 目的 | アプローチ領域 |
|-----|------|------------|
| **ファンダムブランディング** | 認知度・好意度・想起度・推奨意向度の引き上げ | 意識変容・態度変容 |
| **ファンダムプロモーション** | 購買意向・店頭送客・実購買・行動意欲の向上 | 行動変容（売上に近い） |

**重要な原則**：戦略（何のためにやるか）はブランド・企業側が主体で設計し、戦術（どうやるか）はIP（のファンダム）側を主体に据える。自社ターゲットとIPターゲットの親和性だけで判断すると失敗する。あくまで「自社ブランド・商品の課題解決」が起点。

## STEP 2：目標設計（KGI／KPI）

### KGI

| 種別 | KGI設定の傾向 | 測定方法 |
|-----|------------|---------|
| ファンダムプロモーション | 売上（ただし要因特定の解像度は低くなりやすい） | POSの動き・レシート応募数・ECの指定タグ／特設サイト経由の購入数 |
| ファンダムブランディング | 好意度・推奨意向度・愛着度・購入意向 | SNS上の定性コメント、またはブランドリフト調査で定量化。単年ではなく数年単位で見る |

### KPI（両者共通で見る項目）

- インプレッション
- 再生回数
- サイト訪問者数
- 会員登録者数
- SNS上でのエンゲージメント率（反応数）
- 定性コメント

## STEP 3：IP属性の理解

IPは大きく3カテゴリ・12ジャンルに分かれ、それぞれファンダムの特性が異なる。

### 二次元（キャラクター）

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **アニメ・漫画** | 漫画→アニメ化→映画化の過程でファンダムの母数・熱量が拡大。アニメ化の成否がファンダム形成を大きく左右する。マス化するとタイアップが乱立し、ブランド連想が薄まりやすい |
| **キャラクター** | ファンダムの含有数が最大。普遍性を獲得したキャラクター（ディズニー・ジブリ・キティ等）は半永久的にファンダムを生む。それ以外は期間限定ファンの可能性があり鮮度の見極めが必要 |

### 三次元（実在人物）

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **アイドル** | 規模・熱量ともに大きい。トータル訴求が可能。ファンダムプロモーション向き。マス起用は半年以上前からのスケジュール確保が必要 |
| **K-POP** | 男女とも規模・熱量が大きく同性ファンダム率も高い。プロモーション・ブランディング両方対応可能。活動寿命の短さ・兵役等のリスクに留意 |
| **音楽アーティスト** | レジェンド級はファンダムは多いがライト層が少ない。新人は母数少なく熱量高い。ブランディング寄りの起用が効果的 |
| **スポーツ** | チーム単位のファンダムが選手単位より母数が多い（大谷翔平等の例外あり）。文脈接続の難度が高くブランディング向き |
| **俳優** | 役へのファンダムか本人へのファンダムかを見極める（写真集売上が参考指標）。ブランディング向き |
| **2.5次元俳優** | 二次元＋三次元の相乗効果で大きなファンダムを形成しやすい |
| **ミュージカル** | 熱量は大きいが母数は少なめ。国民級の劇団以外は作品軸・役者軸のファンダムが中心 |
| **声優** | 声優自身とキャラクターのファンダムが分離している。ファンダムプロモーション向き |
| **お笑い芸人** | ネタ以外（思想・人間性の発信）でファンダム化するケースに注目 |

### バーチャル

| ジャンル | ファンダムの特徴 |
|---------|--------------|
| **Vtuber** | 熱量が非常に高い。スキャンダルリスクが低い |
| **YouTuber/インフルエンサー** | 栄枯盛衰が激しい。炎上リスクにも留意。KOL（専門領域インフルエンサー）は別枠 |
| **ゲーム** | ハード／ソフト／キャラクターの3分類。メディアミックス展開でライト層が拡大しやすい |

## STEP 4：自社接続の検証（IPと自社をつなげる8ヶ条）

IP選定は「今勢いがあるから」という手段の目的化を避け、以下8項目をすべて確認する。

```markdown
## IP選定チェックリスト

- [ ] ファンのデモグラがターゲットと一致するか
- [ ] コストパフォーマンスと見合うか（キャスティング費だけでなく、オリジナルコンテンツ制作・衣装/メイク・書き下ろし・SNS告知など想定稼働を精緻化したか）
- [ ] デジタルで強力なパワーを持つか（フォロワー数は決定打ではないが、ファンダムの含有率・共犯関係構築の可能性を見る）
- [ ] ブランドと掛け合わせるエンタメのトンマナが合っているか（世界観・思想・スタンス・クリエイティブの整合性）
- [ ] アクション（購買・口コミ・推奨）するファンダムがついているか
- [ ] 過去に同業種でのコラボ事例はないか（IP側にとってそのカテゴリーが「初」であるほど熱狂を生みやすい）
- [ ] （人物IPの場合）本人が自分の言葉で語れるか（「言わされている感」は逆効果）
- [ ] ファンダムが喜ぶものになっているか（企業の課題解決とファンダムの喜びを両立できているか）
```

## STEP 6：IPの解像度を上げるリサーチ

```markdown
## IPリサーチ実施項目

### 現地現物
- ライブ・イベントに実際に足を運ぶ（デモグラの乖離、服装・持ち物・同伴者・物販の売れ筋・リアクション・ライト層/ファンダム比率を観察）

### SNS上の口コミ確認
- まずAPI（X API・YouTube Data API等）で言及量・エンゲージメント・濃度指標を定量取得する（詳細はSTEP8を参照）
- その上で、上位候補に対してコメント内容の質・反応スピードを目視でサンプル確認する（フォロワー数より「濃度」を重視）
- 直接（公式アカウントの発信）と間接（クチコミ分析・ネットニュース）の両方を対象にする

### IP側への直接ヒアリング
- NDA締結の上、再生回数・ファン属性・支持国・反応の良いコンテンツ等、ステークホルダーしか持たない情報を確認する

### 他社事例調査
- 固有名詞またはジャンル軸で先行事例を調査する（参考情報として扱い、同一IP起用の前提にはしない）
```

## STEP 7：ターゲティング（IPをどのゾーンで狙うか）

縦軸「マス（みんな知っている）／ニッチ（一部が知っている）」×横軸「可処分精神 高／低」の4象限で判断する。

| 象限 | 特徴 | 評価 |
|-----|------|------|
| **マス×可処分精神高** | 規模・熱量ともに最大だが、メガブランド以外は起用困難。高コスト・高頻度使用によるブランド連想の希薄化・厳格な使用ルールが弱点 | メガブランド向け |
| **マス×可処分精神低** | リーチはできるがファンダムが少なく、ヒトもモノも動かない | タイアップ非推奨（従来型の認知目的なら可） |
| **ニッチ×可処分精神高（セグメントマス）** | 最も多くの企業が組みやすいゾーン。低コスト・低使用頻度でブランド連想がされやすく、「フックアップしてくれた」という好意的解釈（オタクの恩返し）が生まれやすい | **最推奨** |
| **ニッチ×可処分精神低** | 対象外 | 除外 |

### セグメントマスを見つける5つの方法

1. **専門メディアで見つける**：プラットフォーマーのネクストブレイク紹介企画・ランキング（3位以下が狙い目）
2. **キュレーターから見つける**：各業界の「発掘屋」的存在のSNSをフォローする
3. **専門のファンダムに尋ねる**：「今後どうなっていくと思うか」という未来展望をヒアリングする
4. **ライブ会場の規模で見つける**：目安はZeep（2,000人）以上・武道館未満
5. **3〜4番手を見つける**：作品内の3〜4番手の役者・出演者に着目する

## STEP 8：ファンダムの存在見極め（API主・目視サブ）

ファンダムの規模・熱量の見極めは、**APIによる定量分析を主軸とし、目視確認は「APIで絞り込んだ上位候補の裏付け・違和感チェック」というサブ工程に位置づける**。かつての「数百〜千件を目視」という手動主体の運用は工数と主観の面で本格運用に耐えないため、以下の役割分担とする。

| 手段 | 役割 | 位置づけ |
|-----|------|--------|
| **API分析（主）** | IP候補の網羅的スクリーニング・マス/ニッチ判定・熱量の定量化・経時変化の追跡 | 全候補に対して最初に実施 |
| **目視確認（サブ）** | APIで上位に絞り込んだ候補のみ、コメントの質・内輪文化・炎上リスク・「数値が高いだけでないか」の最終確認 | 上位候補に限定して実施 |

### 主軸となるAPI分析（market-scout連携）

market-scoutが保有するAPI資産（`_shared/agents/market-scout.md`）をIPファンダム分析の観点で活用する。取得指標とAPIの対応は以下の通り。

| 分析観点 | 使用API | 取得する定量指標 |
|---------|--------|--------------|
| **マス/ニッチ軸の数値化** | ① Google Ads API ＋ ② Google Trends | IP名の月間検索ボリューム（絶対量）＋検索トレンドの相対推移。両者でSTEP7の4象限を数値化 |
| **ブレイクの経時変化** | ② Google Trends | 検索トレンドの推移・急上昇。**セグメントマス（マス化直前）の判定＝タイアップの好機とタイミングの把握** |
| **公式規模・二次創作の活発度** | ④ YouTube Data API v3 | 公式チャンネルの登録者数・再生数・投稿頻度／二次創作（MAD・歌ってみた・考察）動画の本数・再生数・コメント数 |
| **SNS言及量・拡散力** | ⑤ X API | IP名・ハッシュタグ・ファンダムネームの言及量・エンゲージメント率・反応スピード |
| **海外ファンダムの規模・熱量** | ⑧ Reddit API | subredditのメンバー数・議論の深さ（アニメ・K-POP等の海外ファンダムに有効） |
| **経済力を伴う購買熱量** | ⑥ 楽天 Ichiba API | IP関連グッズの販売ランキング・レビュー数・価格帯（限定品/高価格帯の売れ行き） |

### IP特化で追加を推奨するデータソース

以下はmarket-scoutに未実装だが、IP協業を本格運用する場合に主軸API群へ追加する。

| データソース | 取得できる定量指標 | 費用・制約 | 特に有効なIP属性 |
|-----------|--------------|---------|-------------|
| **YouTube Data API（ライブ配信特化運用）** | ライブ配信の同時接続数・スーパーチャット金額（`liveBroadcasts`/`liveChatMessages`） | 既存④の枠内・要OAuth・ライブ中のみ | Vtuber・YouTuber・配信者 |
| **pixiv（二次創作プラットフォーム）** | IP・キャラクター別の作品数・閲覧数・ブックマーク数 | 公式APIは限定的・利用規約の範囲で確認 | アニメ・漫画・キャラクター・ゲーム・声優 |
| **メルカリ等フリマ相場** | IP関連商品の中古取引価格・取引量・定価超え率 | robots.txt/規約確認必須・公式APIは限定的 | アイドル・K-POP・キャラクター・アニメ |
| **Spotify API** | monthly listeners・人気トラック・関連アーティスト | 無料・要登録・OAuth | 音楽アーティスト・K-POP |
| **チケット/イベント情報** | ライブ会場キャパ・完売速度・抽選倍率 | サービス依存・一部手動 | アイドル・音楽・2.5次元・ミュージカル |

### サブ工程となる目視確認（上位候補のみ）

APIで絞り込んだ上位IPに対してのみ、以下を目視で最終確認する。**APIでは測りにくい「質」と「リスク」の判定に用途を絞る。**

```markdown
## 目視確認チェック項目（上位候補限定）

### 質の確認（APIの数値が本物の熱量か）
- コメントが「好き」の表明に留まらず、深い考察・分析に及んでいるか
- 二次創作の独創性・クオリティ（量はpixiv/YouTube APIで測れるが質は目視）
- 作品独自の略語・スラング・内輪ネタ・決め台詞が自然に共有されているか
- ファンネーム／ファンダムネームの有無（組織的・高熱量のシグナル）

### リスクの確認（APIでは見えない地雷）
- 炎上・アンチの規模、ネガティブ論調の有無（5ちゃんねる等の定性確認）
- 過去のタイアップでファンダムが反発した事例がないか
- IP側の活動休止・スキャンダルの兆候

### タイアップ整合の確認
- STEP4の8ヶ条（特にトンマナ・自社課題との整合）を満たすか
```

**判断の原則**：APIの数値が高くても、目視で「熱量の質が伴わない」「炎上リスクが高い」と判明した候補は除外する。APIは足切りと優先順位付け、目視は最終ゲートキーパーという役割分担を守る。

## STEP 8+：IP属性別・分析手法マトリクス

IP属性（STEP3の12ジャンル）ごとに、ファンダムが可視化されやすい場所は異なる。属性に応じて重点的に使うAPI・目視確認を切り替えることで、限られた工数で精度を最大化する。

### 二次元（キャラクター）

| 属性 | 主軸API（重点） | 補助API | サブの目視確認 | 地域特性の重要度 |
|-----|-------------|--------|------------|------------|
| **アニメ・漫画** | ② Google Trends（ブレイク推移）＋ ④ YouTube（二次創作・考察動画）＋ pixiv（二次創作の量） | ⑧ Reddit（海外人気）＋ ⑥ 楽天（グッズ売上） | 二次創作の質・独創性、コミケの出展規模、名セリフの共有度 | 低〜中（聖地巡礼のある作品は中：舞台地域の人流を見る） |
| **キャラクター** | ① Google Ads（認知の絶対量）＋ ⑥ 楽天（グッズ売上・ランキング） | ② Google Trends（普遍性の確認）＋ メルカリ相場 | 世代を超えた定着か期間限定人気かの見極め、グッズの購買層 | 低（全国・世界で普遍的なため地域偏在は小さい） |

### 三次元（実在人物）

| 属性 | 主軸API（重点） | 補助API | サブの目視確認 | 地域特性の重要度 |
|-----|-------------|--------|------------|------------|
| **アイドル** | ⑤ X（言及量・熱量）＋ チケット/イベント情報（動員力） | ⑥ 楽天／メルカリ（グッズ転売相場）＋ 地域人流（ツアー地） | ライブ現地の客層・熱狂度、ファンダムネームの浸透度 | 中（全国ツアーの地域別動員に偏在。地方公演の人流を見る） |
| **K-POP** | ⑤ X＋ ⑧ Reddit（世界規模）＋ Spotify（monthly listeners） | チケット情報／メルカリ相場 | 同性ファンダム率、世界各国の言語での言及、行動力の質 | 中（国・都市単位の偏在。国別・都市別の関心度を見る） |
| **音楽アーティスト** | ② Google Trends（ブレイク推移）＋ Spotify（規模・関連アーティスト） | ⑤ X＋ チケット/ライブ会場規模（Zeep以上か）＋ Google Trends地域別 | ライト層/コア層比率、可処分精神を占める曲数の多さ | 中（地元・ライブ地に偏在。Google Trendsの地域別関心度を活用） |
| **スポーツ** | **⑤ X＋ 地域人流データ（国交省人流OD/RESAS）＋ ① Google Ads** | ⑥ 楽天（グッズ）＋ チケット/スタジアム動員 | チーム軸か選手軸か、文脈接続の可否、地元との結びつき | **最高（地元密着型は本拠地地域が命。後述の地域分析を必須とする）** |
| **俳優** | ① Google Ads（本人名の検索量）＋ ⑥ 楽天（写真集売上） | ② Google Trends（作品連動の増減） | 役ファンか本人ファンか（写真集売上が指標）、本人の言語化力 | 低（全国区。ご当地出身タレントの地元訴求のみ中） |
| **2.5次元俳優** | ④ YouTube（舞台関連）＋ ⑤ X＋ チケット情報 | pixiv（二次創作） | 二次元原作と俳優本人の両ファンダムの重なり | 低〜中（公演都市に一時的偏在） |
| **ミュージカル** | チケット/イベント情報（抽選倍率）＋ ⑤ X | ① Google Ads（劇団/作品名） | 作品軸/役者軸/箱推しの別、独自ファン用語 | 中（劇場所在地・公演都市に強く偏在） |
| **声優** | ④ YouTube（配信・歌ってみた）＋ ⑤ X＋ ⑥ 楽天 | pixiv／チケット情報（イベント） | キャラと声優本人のファンダム分離度、SNSでの直接交流 | 低（全国・オンライン中心） |
| **お笑い芸人** | ④ YouTube（チャンネル・ラジオ切り抜き）＋ ⑤ X | ① Google Ads（劇場/ライブ集客） | ネタ軸か思想・人間性軸か、書籍/ライブの動員 | 低〜中（ご当地芸人・地方拠点の場合は中） |

### バーチャル

| 属性 | 主軸API（重点） | 補助API | サブの目視確認 | 地域特性の重要度 |
|-----|-------------|--------|------------|------------|
| **Vtuber** | ④ YouTube（同時接続数・スパチャ・登録者）＋ ⑤ X | ⑥ 楽天／メルカリ（グッズ） | スパチャ額＝直接支援熱量、ファンダムの熱狂度、炎上リスク | 低（オンライン中心。リアルイベント時のみ会場地を見る） |
| **YouTuber/インフルエンサー** | ④ YouTube（登録者・エンゲージメント）＋ ⑤ X | ② Google Trends（栄枯盛衰の推移） | 炎上履歴・アンチ規模、KOLか否か、離脱ファンの兆候 | 低（全国・オンライン中心） |
| **ゲーム** | ② Google Trends＋ ④ YouTube（実況・二次創作） | ⑧ Reddit（海外）＋ ⑥ 楽天／pixiv | ハード/ソフト/キャラのどこにファンダムがつくか | 低（全国・世界規模。地域イベント時のみ中） |

### マトリクス活用の原則

- **属性を最初に確定してから分析に入る**：同じ「認知度」でもアニメと音楽アーティストで見るべきAPIが違う。属性判定（STEP3）を飛ばさない
- **主軸APIで足切り→補助APIで裏付け→上位のみ目視**：全属性共通で、目視は最後の限定工程
- **経時変化は全属性で② Google Trendsを併用**：ブレイクのタイミング把握はタイアップ成否に直結するため属性を問わず追う
- **地域特性の重要度が「中」以上のIPは地域分析を必ず実施する**：特にスポーツ（地元密着型）は地域データの重み付けを最大にする。詳細はSTEP8++を参照

### 分析実行フロー（推奨）

```
STEP A：IP属性の確定（STEP3）
  → 12ジャンルのどれかを特定し、上記マトリクスで使うAPIを決める

STEP B：主軸APIでスクリーニング（全候補）
  → マス/ニッチ軸の数値化＋熱量の定量化＋Google Trendsでブレイク推移確認
  → 候補を上位数件に絞り込む

STEP C：補助APIで裏付け（絞り込んだ候補）
  → 属性特化のデータソース（pixiv/Spotify/メルカリ等）で熱量を多角的に確認

STEP D：目視確認（上位候補のみ・サブ工程）
  → 熱量の質・炎上リスク・8ヶ条整合を人の目で最終チェック

STEP E：8ヶ条（STEP4）との最終照合
  → 数値・熱量が高くても定性条件（自社課題・トンマナ・同業種初か）を満たすか確認
```

### API活用時の必須ルール

- **各APIのレート制限・利用規約を厳守する**：market-scoutの「API全体の共通ルール」に従う。生データは保存せず、ファンダム分析指標に変換して記録する
- **経時変化を記録する**：単発取得ではなくGoogle Trends・YouTube登録者数等を定期取得し、ブレイクの兆し（セグメントマス→マス化の直前）を捉える
- **個人特定情報を収集しない**：ファンダムの規模・熱量の集計に用途を限定し、個々のファンのプロフィール収集は行わない

## STEP 8++：地域特性・人流データ分析（地元密着型IP・イベント施策向け）

IPによってはファンダムが全国均一ではなく**特定地域に強く偏在**する。特に地元密着型のスポーツチームは「本拠地地域との結びつき」がファンダムの核であり、全国指標だけで評価すると本質を見誤る。また、コラボイベント・ポップアップ等のリアル施策では**開催地の人流**が動員を左右する。ここでは地域データを分析に組み込む方法を定義する。

### 地域データが重要になるケース

1. **地元密着型IP**：プロスポーツチーム（野球・サッカー・バスケ等）、ご当地アイドル、地方拠点の劇団・芸人など。本拠地/活動地域のファンダム密度が全国平均と大きく乖離する
2. **リアルイベント施策**：コラボカフェ・ポップアップ・スタジアムコラボ・展示会など、特定の場所に人を集める施策。開催地の人流・商圏が成否を決める
3. **地域限定プロモーション**：特定エリアの店頭送客・地域限定商品など

### 活用するデータソース（地域・人流）

market-scoutに新規追加を推奨する地域データソース。多くが**無料・公式**で利用できる。

| データソース | 取得できるデータ | 費用・形式 | 分析での価値 |
|-----------|--------------|---------|-----------|
| **国土交通省 全国人流オープンデータ** | 1kmメッシュ別・市区町村別の滞在人口（時間帯別・平日/休日別・居住地別） | 完全無料・CSV/API（G空間情報センターで公開） | イベント開催地の人流規模・来訪者の居住エリアを把握。地元密着度の定量化 |
| **RESAS-API（地域経済分析システム）** | 人口動態・From-to分析（滞在人口）・観光・産業データ | 無料・API（要利用登録） | 本拠地地域の人口構成・流入元エリア・滞在人口率の全国ランキング |
| **モバイル空間統計 人口マップ（モバ空マップ）** | 携帯ネットワーク由来の人口分布（無料版） | 無料版あり（詳細・属性別は有料） | イベント地の実際の人の集まり・時間帯変動の確認 |
| **② Google Trends（地域別関心度）** | IP名の都道府県別・市区町村別の検索関心度 | 既存②の枠内・無料 | ファンダムの地理的偏在を最小工数で把握（最初の当たり付けに最適） |
| **自治体オープンデータ／スタジアム動員記録** | 試合・イベントの動員数、地域人口 | 無料（公開範囲による） | チームの地元浸透度・観客動員の実数 |

### スポーツIP（地元密着型）の地域重み付け分析

スポーツIPは地域特性の重要度を**最高**とし、全国指標より地域指標を優先して評価する。

```markdown
## 地元密着型スポーツIPの分析フレーム

### STEP 1：本拠地地域の特定とファンダム密度
- ② Google Trends の地域別関心度で、チーム名の検索が本拠地県に集中しているか確認
- RESAS-APIで本拠地の人口規模・年齢構成を取得（ターゲット層と地域人口の一致を見る）

### STEP 2：地元密着度スコアの算出（全国指標に対して地域を重み付け）
以下を通常のファンダム定量スコア（STEP8）に加算・重み付けする：
- 本拠地県での検索関心度 ÷ 全国平均（地域集中度。高いほど地元密着が強い）
- スタジアム/アリーナの平均動員数 ÷ 本拠地人口（地域浸透率）
- ホームゲーム開催時の周辺人流の増加率（国交省人流ODで測定）

→ 地元密着型IPでは「全国のSNS言及量」より「本拠地での地域集中度・浸透率」を重視する。
　 全国的には無名でも、特定地域で圧倒的な支持を持つチームは、その地域限定の施策で高い効果を出す。

### STEP 3：地域文脈での8ヶ条照合
- 自社が本拠地地域に店舗・拠点・配荷を持つか（地域施策の実行可能性）
- 地域の誇り・アイデンティティとブランドが結びつくか（「わかってるね感」の地域版）
```

### イベント施策の人流分析

コラボカフェ・ポップアップ・スタジアムコラボ等のリアル施策では、開催地選定と効果予測に人流データを使う。

```markdown
## イベント人流分析フレーム

### 開催地選定（事前）
- 国交省人流ODで候補地の滞在人口・来訪者の居住エリアを比較
- ターゲットファンダムが多いエリア（Google Trends地域別関心度）と人流が多いエリアの重なりを狙う
- RESAS From-to分析で「どのエリアから人が来るか」を把握し、告知の配信エリアを最適化

### 効果予測・実測（事中・事後）
- イベント期間中の開催地周辺の人流増加率を国交省人流OD／モバ空マップで測定
- 平常時との差分＝イベントによる誘客効果として記録
- 曜日・時間帯別の人流ピークに合わせてイベント運営・在庫を最適化
```

### 地域データ活用の必須ルール

- **地元密着型IPは地域指標を全国指標より優先する**：全国のSNS言及量が少なくても、本拠地での地域集中度が高ければ高評価とする。これがスポーツIP評価の肝
- **人流データは属性別・時間帯別で見る**：単純な総数ではなく、ターゲット層（年代・居住地）が来訪しているかを確認する
- **無料データソースを優先する**：国交省人流OD・RESAS-API・Google Trends地域別・モバ空マップ（無料版）で大半をカバー。詳細な属性分析が必要な場合のみ有料のモバイル空間統計等を検討
- **市区町村メッシュの粒度に注意**：国交省人流ODは1kmメッシュ〜市区町村単位。個店商圏の分析には粒度が粗い場合があるため用途に応じて使い分ける
- **個人特定情報を収集しない**：あくまで集計された人流・地域統計を用い、個人の移動追跡は行わない

### 地域分析の実行フロー（地域特性の重要度「中」以上のIP）

```
STEP F：Google Trends地域別関心度（②）でファンダムの地理的偏在を把握
  → 全国均一か、特定地域集中か（この時点で地域分析の要否を判断）

STEP G：地元密着型（スポーツ等）の場合
  → RESAS-API＋国交省人流ODで本拠地の人口構成・地域集中度・浸透率を算出
  → 地元密着度スコアを通常のファンダムスコアに重み付け加算

STEP H：リアルイベント施策を伴う場合
  → 国交省人流OD／モバ空マップで開催候補地の人流を比較・選定
  → ターゲット居住エリア × 人流の重なりで最適地を決定

STEP I：地域文脈での8ヶ条照合（STEP4）
  → 地域の誇り・アイデンティティとの結びつき、自社の地域拠点の有無を確認
```

## STEP 9：予算設計

### ファンダムのお金の優先順位

推しへの可処分所得は無限ではなく、以下の優先順位で使われる（優先度が下がるほどタイアップの効果は限定的になる）。

1. ライブ・ツアー
2. イベント・グッズ・ファンクラブ
3. コラボ商品・アイテム

IP側のメイン活動（ライブ・ツアー等）が繁忙な時期は、コラボ企画の優先順位が相対的に下がる点をあらかじめ織り込んでKGI（特に売上目標）を固めに設定する。

### 予算配分の目安

- 一般的な推し活の月間支出目安：約16,000円前後（2万円を超えない範囲に収める企画は成功確率が高い）
- お土産（インセンティブ）予算：全体予算の**最大10%**を目安に変動費として確保する

## STEP 11：伝搬設計

コンテンツを作るだけでは伝わらない。「どこで着火し、どこに広げ、どこで見せるか」をSNS単位で設計する。

| 役割 | 定義 | 該当しやすいSNS |
|-----|------|--------------|
| **着火SNS** | クチコミを最初に生む場所（コンテンツそのものは不要） | 対象ファンダムの主戦場を個別リサーチして判断 |
| **拡散SNS** | 情報を広げる場所 | X・TikTok（Instagramは閉じたコミュニティの集合体のため拡散向きではない） |
| **受け皿SNS** | コンテンツを享受する場所 | 任意のSNS／Webサイト等 |

### 発信順序のルール（「企業とともに発話させる」）

```markdown
## 発信ルール

1. 一次情報は必ず企業・ブランド側から発信する（IP公式から先に発信しない）
   → ファンダムに「Presented by」「Supported by」の文脈を持たせる
2. IP側の発信には必ず企業名・商品名を入れ込む（クリエイティブ本体には必須ではない）
   → 「誰がこのコンテンツを生み出したのか」を明確にする
3. 独自ハッシュタグで両者の結びつきを可視化する
4. （人物IPの場合）IP本人からコラボへの言及・意義表明をしてもらう
```

## STEP 13：越境設計（ファンダムを超えて広げる）

ファンダムは濃度が高い分、母数は狭い。広げるフェーズでは以下4つの手法を使う。

### 近距離トライブス戦略

ファンダムに隣接する「好きなもの」（トライブ）はパーソナライズ化された情報流通の中でつながっている。ファンダムだけでなく隣接トライブへのアプローチを設計する。

### 主戦場を越境ドライブで広げる

自社市場をど真ん中に据えつつ、市場に隣接するトライブを「主戦場」として捉え直す。

### PRで広げる

情報は「自分ゴト」→「仲間ゴト」→「世の中ゴト」の順で広がる。

| 段階 | 定義 | 主なチャネル |
|-----|------|-----------|
| 自分ゴト | 「私に関係がある」と認識される状態 | — |
| 仲間ゴト | 特定コミュニティ内で話題になっている状態 | X・Instagram等の細分化SNS |
| 世の中ゴト | 誰に話しても知っている状態 | テレビ・Yahoo!ニュース等マスPR |

**原則**：すべてが「世の中ゴト」を目指す必要はない。根幹である「自分ゴト」「仲間ゴト」を疎かにして「世の中ゴト」だけを狙うと失敗する。

### 社会ゴトで広げる

世の中の人が反応しやすいイベント・モーメント（進学/就職・転職/引っ越し・結婚/恋愛・季節・恒例イベント・社会的ビッグイベント・記念日・トレンド）と掛け合わせ、興味指数の最大公約数を狙って局所的な影響を拡散させる。
