# スキル：カスタマーサクセス評価（ヘルススコア・NRR・QBR）

**使用するエージェント：** customer-success-analyzer
**入力：** 製品利用ログ・CRMデータ・商談記録・QBR記録・契約情報
**出力：** ヘルススコア・NRR/チャーン率・チャーンリスク評価・アップセル/クロスセル仮説・QBRアジェンダ

---

## 評価の原則

**「顧客の成功なくして自社の継続的成長はない」**
toBビジネスの収益の大部分はリピート・更新・拡大から生まれる。チャーン（解約）を防ぎNRRを高めることが、新規獲得コスト以上の価値を持つ。

---

## STEP 1：ヘルススコアの算出

5つのカテゴリを0〜10点で評価し、重み付けして100点満点に換算する。

| カテゴリ | 指標 | 重み | 評価方法 |
|---------|------|------|---------|
| **エンゲージメント** | ログイン頻度・機能活用率 | 30% | 製品ログデータ |
| **成果実現度** | 当初約束したKPIの達成率 | 30% | QBR・定期レポート |
| **関係の深さ** | ステークホルダーとの接触頻度・チャンピオン度 | 20% | CRMデータ |
| **拡大ポテンシャル** | 追加部門・追加ユーザーの見込み | 10% | ヒアリング・組織情報 |
| **リスク要因**（逆転指標） | 契約更新時期・担当者変更・競合接触 | 10% | 商談記録・情報収集 |

```python
総合ヘルススコア = (
    エンゲージメントスコア × 0.30 +
    成果実現度スコア     × 0.30 +
    関係の深さスコア     × 0.20 +
    拡大ポテンシャルスコア × 0.10 +
    (10 - リスク要因スコア) × 0.10
) × 10   # 100点満点に換算
```

**判定基準：**
- 🟢 **80〜100点**：Healthy。アップセル・クロスセルの好機
- 🟡 **60〜79点**：Neutral。定期的なフォローアップが必要
- 🔴 **0〜59点**：At Risk。チャーン防止のための緊急対応が必要

---

## STEP 2：主要KPIの定義と算出方法

### NRR（Net Revenue Retention）
```
NRR = （期末ARR − チャーンARR − 縮小ARR + 拡大ARR）÷ 期初ARR × 100

目安：
100%以上 = 既存顧客だけで成長している（理想）
90〜100% = 概ね健全
90%未満  = チャーンが拡大を上回っている（要対策）
```

### チャーン率
```
月次チャーン率 = 月中に解約した契約数（ARR）÷ 月初の契約数（ARR）× 100

目安：
1%未満/月 = 優秀（年率換算で12%以下）
1〜2%/月  = 要改善
2%超/月   = 緊急対策が必要
```

### Time to Value（TTV）
```
TTV = 契約日から顧客が初めて価値を実感した日までの期間

TTVが短いほどオンボーディングが成功している。
TTVと長期定着率の相関を継続的にトラッキングする。
```

## STEP 3：チャーンリスクの早期検知

```markdown
## チャーンリスクシグナルチェックリスト

### 使用状況シグナル
- [ ] ログイン頻度が直近30日で50%以上低下している
- [ ] コアとなる機能の利用率が大幅に低下している
- [ ] サポートチケット数が急増している（製品への不満）
- [ ] ヘルプドキュメントの閲覧が急増している（習熟できていない）

### 関係シグナル
- [ ] 担当者（チャンピオン）が退職・異動した
- [ ] ステークホルダーからのメールへの返信が遅くなった
- [ ] QBR（定期レビュー）のキャンセルが続いている
- [ ] 競合製品の評価を始めた（G2・比較サイトへのアクセス等）

### ビジネスシグナル
- [ ] 顧客企業が業績悪化・リストラを発表した
- [ ] 契約更新の交渉で値下げ要求が来た
- [ ] 導入部門以外への展開が止まっている

### 契約シグナル
- [ ] 更新まで90日を切った（まだ次期契約の話し合いが始まっていない）
- [ ] 当初設定したKPIが達成されていない
```

1つでも該当すればリスクレベルを1段階引き上げ、3つ以上該当する場合は「高」と判定する。

## STEP 4：アップセル・クロスセルの仮説生成

### アップセルの判断基準
```markdown
以下が揃っている場合はアップセル提案の好機：
□ ヘルススコアが80点以上（Healthy状態）
□ 現在の契約範囲でユーザー数・利用量が上限に近づいている
□ 上位プランの機能が顧客の課題解決に明確につながる
□ 経済的意思決定者との関係が良好
```

### クロスセルの判断基準
```markdown
以下が揃っている場合はクロスセル提案の好機：
□ 既存導入部門での成功事例が出ている（数値付き）
□ 隣接部門が同様の課題を持っていることが確認できている
□ 既存チャンピオンが隣接部門とのコネクションを持っている
□ 既存導入から6ヶ月以上経過し、活用が定着している
```

## STEP 5：QBR（定期ビジネスレビュー）の設計

```markdown
## QBRアジェンダテンプレート（60分）

【15分】過去期間の振り返り
- 約束したKPIの達成状況（数値）
- 主な成果・使用事例

【15分】現状の課題・フィードバック
- 顧客が感じている課題・改善要望
- 製品への期待と現実のギャップ

【15分】次期の計画
- 次の期間の目標設定
- 活用度向上のための追加支援

【15分】戦略的な議論
- ビジネスの変化・新しい優先事項
- 拡大（アップセル・クロスセル）の可能性
```
